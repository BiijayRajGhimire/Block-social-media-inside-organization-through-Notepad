# Block-social-media-inside-organization-through-Notepad
We have three ways to block social media, Notepad, firewall outbound for specific people and DNS through Hostname A Name for all inside employees blocks social media  
Block only facebook.com in PC1
	Run Notepad as administrative
	Click in local disk, windows, system32, divers, etc., host
	Type 127.0.0.1 facebook.com
	Type 127.0.0.1 www.faceboo.com
